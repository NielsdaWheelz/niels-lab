# Fractal Chat: A Reading Companion for Infinite Text

*A chat-first reader built to ingest messy documents.*

---

## System Architecture

### Document ingestion

Three inputs:

**1) URLs** - Mozilla [Readability](https://github.com/mozilla/readability) strips junk and keeps the article.

```typescript
const article = await extractMainFromUrl(normalizedUrl)
// { title, content, textContent, byline, publishedTime, meta }
```

Single pages aren't enough, so there's a breadth-first crawler:

```typescript
const pages = await crawlSite(normalizedUrl, {
  maxPages: 50,
  sameHostOnly: true,
  delayMs: 500
})
```

Aggregate pages or keep them separate; archives and docs need both.

**2) PDFs** - Dual extractor because PDFs are hostile:

```typescript
const parsed = await extractPdfText(buffer);
if (!textResult?.text?.trim()) {
  return runFallbackExtraction(buffer, primaryError);
}
```

**3) EPUBs** - EPUB is structured HTML. Pull chapters, glue them, keep metadata.

```typescript
const book = await EPub.createAsync(tmpPath);
const htmlChapters = await Promise.all(
  book.flow.map((ch) => book.getChapterRawAsync(ch.id))
);
```

### Metadata resolution

Site metadata is sloppy. The pipeline combines rules and LLM inference:

```typescript
const { object } = await generateObject({
  model: openai("gpt-5-nano"),
  schema: metadataSchema,
  prompt: contextualPrompt,
});
```

Schema-constrained output stops hallucinated fields.

### Chunking and embeddings

Text gets split with LangChain's recursive splitter to keep concepts intact:

```typescript
const splitter = new RecursiveCharacterTextSplitter({
  chunkSize: 500,
  chunkOverlap: 50,
});
```

Embeddings: OpenAI `text-embedding-3-small` at 512 dims to balance cost and recall.

```typescript
const { embeddings } = await embedMany({
  model: openai.textEmbeddingModel('text-embedding-3-small'),
  values: chunkTexts,
  providerOptions: { openai: { dimensions: 512 } },
});
```

Stored in Postgres with `pgvector` so cosine search runs in the database:

```sql
SELECT *, 1 - (embedding <=> $1::vector) as similarity
FROM document_chunks
ORDER BY similarity DESC
LIMIT $2
```

No external vector DB; fewer moving parts.

## Annotation System

### Character-offset anchoring

Anchors stick to text, not the DOM:

```typescript
const annotation = {
  start: 1420,
  end: 1580,
  quote: "...",
  prefix: "...",
  suffix: "...",
};
```

If HTML shifts, offsets still line up unless the words change. Prefix/suffix support fuzzy re-anchoring after minor edits.

### Permission inheritance

Annotations inherit document visibility. Groups add another layer: share a doc with a group, everyone can read; public annotations from members are visible to the group; owner keeps admin rights.

## AI Interface

### Document-grounded chat

Chats are bound to a document; the system prompt names it and its author and reminds the model it has a search tool. Less drift, better answers.

```typescript
systemPrompt += `\n\nContext: You are discussing the document "${document.title}"`;
if (authorNames) systemPrompt += ` by ${authorNames}`;
systemPrompt += `. You have access to a searchDocuments tool.`;
```

### Retrieval as a tool

Semantic search is exposed to the model so it can pull evidence when needed:

```typescript
tools: {
  searchDocuments: tool({
    description: `Search documents for matching chunks of text.`,
    inputSchema: z.object({
      query: z.string(),
      topK: z.number(),
      searchScope: z.enum(['current', 'mentioned', 'all']),
    }),
    execute: async ({ query, topK, searchScope }) => {
      return await embedAndSearch(userId, query, topK, docIds);
    },
  }),
}
```

RAG as agentic tool use instead of a fixed pipeline.

### Mentions for cross-document context

Mention syntax pulls other docs or authors into scope:

```
What did @[Meditations](document:abc123) say?
How does this compare to @[Marcus Aurelius](author:xyz789)?
```

Regex parse, expand search scope, synthesize across sources.

## Technical Choices

- React Router 7: SSR with focused client islands; loader/action keeps data flow honest.
- Drizzle ORM: Type-safe SQL without Prisma magic; vector queries stay visible.
- Better-Auth: Auth as a library; no external service tax.
- Vercel AI SDK: Streaming and tool calls solved; reinventing adds no value.
- Stripe: Billing is solved; don't cosplay a payments company.
- Supabase Storage: S3-compatible PDF storage; Postgres handles pgvector.

---

## Lessons

1) Metadata beats content in difficulty. Sites are inconsistent; expect cleanup.  
2) Permissions grow teeth fast. Hierarchies and overrides are inevitable.  
3) PDFs fight back. Test against pathological files or users will do it for you.  
4) LLMs work best as tools with constraints, not as oracles.  
5) Visual coherence reduces cognitive load; good UI teaches itself.
