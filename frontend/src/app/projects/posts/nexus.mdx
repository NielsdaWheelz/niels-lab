Nexus is where I read. It ingests EPUBs, PDFs, web articles, YouTube videos,
and podcast episodes, renders them in a pane-based reader, and answers
questions about them with an LLM whose citations resolve back to the passage.
It runs at [nexus.nielseriknandal.com](https://nexus.nielseriknandal.com),
ships an [Android shell](https://github.com/NielsdaWheelz/nexus-web/releases/tag/android-v0.2.13)
through GitHub releases, and captures pages with a
[Manifest V3 extension](https://github.com/NielsdaWheelz/nexus-web/blob/4fc8401fec9e8ba218d156a0664943303af57285/apps/extension/manifest.json).
It exists because my reading was scattered: highlights in one app, notes in
another, chat context brittle and unshareable.

I built it twice. The first repo, [nexus](https://github.com/NielsdaWheelz/nexus),
ran from 2025-11-25 to 2025-12-05: FastAPI, Celery and Redis, Clerk auth,
byte-offset highlights, pgvector search. Its
[README](https://github.com/NielsdaWheelz/nexus/blob/f2876950a709a22ae6bac1eea6e69fb4233b055d/README.md)
promised highlights that survive re-ingestion; the
[remap task](https://github.com/NielsdaWheelz/nexus/blob/f2876950a709a22ae6bac1eea6e69fb4233b055d/backend/app/tasks/remap.py)
was a stub I never wrote. Chat was never started. The repo ends in a two-day
burst of spec commits, and six days later
[nexus-web began](https://github.com/NielsdaWheelz/nexus-web/commit/c7f901370575a8b6220051d06b73b4fdf38c3ddc)
from an empty README. No code crossed over; auth, job queue, and anchor
semantics all changed.

Three reversals define the second system. The founding
[constitution](https://github.com/NielsdaWheelz/nexus-web/commit/b11d164f4060c9f7be5838e6dba6ac784c2af842)
mandated browsers calling FastAPI directly; eleven days later a
[Next.js BFF](https://github.com/NielsdaWheelz/nexus-web/commit/468da77c8edae0e48cf8b364c19c43567cac0574)
stood in front of it, leaving one direct browser path — SSE, authenticated by
[60-second single-use JWTs](https://github.com/NielsdaWheelz/nexus-web/blob/4fc8401fec9e8ba218d156a0664943303af57285/python/nexus/services/stream_tokens.py)
with a replay-prevention table. Background work started on Celery and Redis,
as v1 had; in March I [cut both](https://github.com/NielsdaWheelz/nexus-web/commit/47a88de6f4b64809e1f8b34a0a03a83b0fd338a0)
for a Postgres job queue, removing an infrastructure dependency outright. And
v1's byte offsets became
[Unicode codepoint ranges](https://github.com/NielsdaWheelz/nexus-web/blob/4fc8401fec9e8ba218d156a0664943303af57285/apps/web/src/lib/reader/textOffsets.ts)
over canonical text: when the client's canonicalization disagrees with the
server's, the reader
[disables highlighting](https://github.com/NielsdaWheelz/nexus-web/blob/4fc8401fec9e8ba218d156a0664943303af57285/apps/web/src/lib/highlights/selectionToOffsets.ts)
rather than write a bad anchor. PDFs get a separate
[page-geometry anchor](https://github.com/NielsdaWheelz/nexus-web/blob/4fc8401fec9e8ba218d156a0664943303af57285/python/nexus/schemas/highlights.py).

Chat is not a request. Sending a message creates a
[durable run](https://github.com/NielsdaWheelz/nexus-web/commit/a5d1a6c154fdf02573bed547f4a805710cb8328a)
the worker executes while the browser tails SSE and reconciles from stored
state. A citation is an edge in one flat
[resource_edges table](https://github.com/NielsdaWheelz/nexus-web/commit/ee250de731043211f6c90fd5a9d953b209f55b70)
that replaced the per-feature link stores.

By git log on 2026-08-09: 1,571 commits since December 2025, 211 Alembic
migrations, and 562 commits carrying Claude co-author trailers — I direct the
build; agents write a large share of it.

The reading is no longer scattered. The operating is.
